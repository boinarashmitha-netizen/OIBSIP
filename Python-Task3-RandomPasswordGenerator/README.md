# Random Password Generator

This is a simple Python program that generates a random password.
The user can enter the required password length.

## How it works

1. The user enters the required password length.
2. The program creates a set of letters, numbers, and special characters.
3. It randomly selects characters from the set.
4. The selected characters are joined together to create the password.
5. The generated password is displayed.

## Technologies Used

- Python
- random module
- string module

## How to Run

1. Open the `random_password_generator.py` file.
2. Run the Python program.
3. Enter the required password length.
4. The program will generate and display a random password.

## Example Output

```text
Random Password Generator
Enter the length of the password: 8
Generated Password: aB7@xP2!
```

## Features

- Generates random passwords.
- Allows the user to choose the password length.
- Uses letters, numbers, and special characters.
- Simple and beginner-friendly Python program.
